# PROBOOST Analytics Backend

Аналитика сайта с отчётами в Telegram и анализом через OpenAI.

## 🚀 Установка и запуск

### 1. Копируешь `.env.example` в `.env` и заполняешь:

```bash
cd backend
cp .env.example .env
```

В `.env` добавляешь:
- `TG_TOKEN` - **новый токен** от BotFather (пересоздай, старый скомпрометирован!)
- `TG_CHAT_ID` - твой Telegram ID (узнаешь у @userinfobot)
- `OPENAI_API_KEY` - ключ от OpenAI (sk-...)
- `MONGO_URL` - ссылка на MongoDB (опционально, без неё работает в памяти)

### 2. Установка зависимостей:

```bash
cd backend
npm install
```

### 3. Запуск Backend:

```bash
npm start
```

В терминале увидишь:
```
✅ MongoDB подключена (если настроена)
🚀 Analytics API работает на http://localhost:5000
```

### 4. Запуск Telegram Bot (в отдельном терминале):

```bash
npm run bot
```

Результат:
```
🤖 Telegram Bot запущен
   Отправляет отчёты в чат: 123456789
```

## 📊 Как это работает

### На сайте:
- Отслеживаем **просмотры** (page_view)
- Отслеживаем **скролл** (scroll depth)
- Отслеживаем **клики по статьям** (article_click)
- Отслеживаем **время на сайте** (page_unload)
- Отслеживаем **CTA клики** (кнопки)

### В Backend:
- Получает события с фронта
- Сохраняет в MongoDB
- Анализирует через OpenAI
- Отправляет отчёты в Telegram

### В Telegram боте доступны команды:
- `/report24` - подробный анализ за 24 часа (с рекомендациями от OpenAI)
- `/report7` - анализ за 7 дней
- `/stats` - быстрая статистика
- `/help` - справка

Плюс **автоматические отчёты** каждый день в **9:00** и **18:00**

## 🔗 API Endpoints

```
POST /api/analytics
  Отправить событие аналитики
  Body: { event, url, referrer, userId, ... }

GET /api/events?hours=24
  Получить события за 24 часа

GET /api/analyze?hours=24
  Получить анализ от OpenAI за 24 часа
```

## 🐛 Troubleshooting

### Backend не запускается:
```bash
# Проверь PORT
lsof -i :5000

# Если занят, измени в .env
PORT=5001
```

### MongoDB connection refused:
```bash
# Либо установи MongoDB локально
# Либо используй MongoDB Atlas (облако)
# Либо оставь как есть (работает в памяти, но данные теряются при перезагрузке)
```

### Бот не отвечает:
```bash
# Проверь TG_TOKEN (должен быть актуален)
# Проверь TG_CHAT_ID (узнай у @userinfobot)
# Проверь интернет
```
