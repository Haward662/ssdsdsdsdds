# Архитектура проекта: SEO-Автоматизатор
**Цель:** Автономный конвейер генерации и публикации экспертных статей в SEO-блог маркетингового агентства.

## Стек технологий:
- **Backend:** Node.js + пакет `node-cron` для расписания
- **База данных:** MongoDB (локальная)
- **Интерфейс управления:** Бот в VK Workspace (Max) через прямое API (Long Polling / HTTP-запросы, СТРОГО БЕЗ Webhooks)
- **Генерация контента:** NeuroAPI
- **Хостинг:** Timeweb Cloud (Ubuntu)

## Главное меню бота (Интерфейс в Max):
Бот должен реагировать на команду `/start` или "Меню" и всегда выдавать визуальные кнопки (не ждать просто текста):
- **"🚀 Генерировать сейчас"** — ручной запуск написания статьи вне очереди по переданной нише и теме.
- **"⏱ Настройки расписания"** — изменение времени автоматического запуска (по умолчанию установлено на 15:00).
- **"📋 Черновики"** — вывод списка неопубликованных статей из БД для проверки.
- **"✅ Опубликовать на сайт"** — ручной перевод выбранной статьи из статуса `draft` в `published`.

## Основная логика работы (Автопилот):
1. Ежедневно в заданное время (15:00) скрипт `node-cron` автоматически инициирует генерацию.
2. Сервер отправляет запрос в NeuroAPI с вшитым системным SEO-промптом.
3. Готовый результат молча сохраняется в MongoDB со статусом `draft`.
4. Бот присылает мне в Max уведомление о готовности новой статьи с inline-кнопками: "✅ Одобрить", "✍️ Редактировать", "❌ Отклонить".
