# Схема данных (MongoDB)

## Коллекция: `articles`
Каждый документ должен содержать следующие поля:
- `title`: String (Заголовок статьи)
- `content`: String (Тело статьи в формате HTML или Markdown)
- `niche`: String (Ниша бизнеса, например: "Доставка еды", "Автосервис")
- `slug`: String (URL-адрес статьи, транслит из title)
- `status`: String (Варианты: 'draft' или 'published')
- `seo`: Object
  - `description`: String (Мета-описание для поисковиков)
  - `keywords`: Array (Список ключевых слов)
- `createdAt`: Date (Дата создания)
