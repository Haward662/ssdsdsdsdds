# Интеграция с VK Workspace (Max)

## Настройки:
- Метод связи: Прямое API (Long Polling). Никаких Webhooks.
- **Авторизация:** Проверка токена в заголовках.
- **Интерфейс:**
  - Команда `/start` вызывает главное меню.
  - Сообщение формата "Ниша: X | Тема: Y" запускает генерацию.
  - Кнопки под текстом: "✅ Опубликовать", "❌ Отклонить", "✍️ Править".
